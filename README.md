# 照片边框 PhotoFrame

一款 macOS 原生 App：给照片**批量加边框**，导出**不损失画质、不改变色彩**的 JPG。

## ⬇️ 下载

**[点击下载 PhotoFrame-1.0.0.dmg](https://github.com/jiewent1-cmyk/PhotoFrame/releases/latest/download/PhotoFrame-1.0.0.dmg)**（约 1 MB）

系统要求：macOS 13 Ventura 或更新版本，Apple 芯片和 Intel 芯片都支持。

## 安装

1. 打开下载的 `.dmg`，把「照片边框」拖到「Applications（应用程序）」文件夹。
2. **第一次打开**时，macOS 可能会提示「无法验证开发者」。这是因为本 App 没有付费的 Apple 开发者签名，并不是病毒。可以用下面任一方法放行：
   - 打开「系统设置 → 隐私与安全性」，滚到页面底部，点「仍要打开」；
   - 或者在「终端」里运行下面这行命令，然后再打开 App：
     ```bash
     xattr -dr com.apple.quarantine "/Applications/照片边框.app"
     ```

## 功能

- **导入**：拖入照片或文件夹，支持 JPG、HEIC、PNG、TIFF、RAW
- **多种边框**
  - 等宽：四边一样宽
  - 画布比例：1:1、4:5、3:2、9:16 等，照片居中
  - 自定义：四边分别设置，比如拍立得风格
  - 尺寸可以按长边百分比或像素设置
- **边框颜色**
  - 常用色板，加上系统取色器
  - 吸管：在照片上点一下取色
  - 自动提取照片的主色调
  - 可以让每张照片用自己的主色调，也可以只给某一张单独设色
- **批量导出**：导出所选或全部，自动跳过损坏的源文件

## 画质保证

- **JPG 原图**：在 DCT 域直接拼接边框，照片部分**不重新压缩**，像素与原图逐位一致。
- **其他格式**：用 Q100、4:4:4 不做色度抽样的高精度编码，精度高于常见编码器。
- **色彩与元数据**：沿用原图的色彩空间（sRGB / Adobe RGB / Display P3）和 ICC 配置文件，不做色彩转换；保留 EXIF、XMP、GPS。
