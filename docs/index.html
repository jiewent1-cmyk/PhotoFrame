导出的 JPG，画质和原图一样

大部分加边框工具会把整张照片重新压缩一遍，每导出一次画质就降一点。照片边框换了一种做法。

100%JPG 原图的照片像素与原图逐位一致
0色彩空间转换
~1s处理一张 2000 万像素的照片
  • ✓
    JPG：在 DCT 域无损拼接直接复用原图压缩后的数据块，只为边框编码新的块。照片部分完全不重新压缩。
  • ✓
    其他格式：高精度编码HEIC、PNG、TIFF 等用 Q100、4:4:4 不做色度抽样的自研编码器，精度高于常见编码器。
  • ✓
    色彩与元数据原样保留沿用 sRGB / Adobe RGB / Display P3 原色彩空间和 ICC；相机、镜头、曝光、GPS 等 EXIF 信息全部保留。
  • !
    自动识别损坏文件拷贝中断、被截断的照片会被标记出来并跳过，不会导出花屏的图。

⚠️ 提示「无法验证开发者」怎么办？

这是因为本 App 没有付费的 Apple 开发者签名，并不是病毒。任选一种方法放行：

方法一：打开「系统设置 → 隐私与安全性」，滚到页面底部，点「仍要打开」。

方法二：打开「终端」，粘贴下面这行命令并回车，然后再打开 App：

xattr -dr com.apple.quarantine "/Applications/照片边框.app"
常见问题

常见问题

支持哪些照片格式？

导入支持 JPG、HEIC、PNG、TIFF、WebP，以及常见的相机 RAW（NEF、CR3、ARW、DNG 等）。导出统一为 JPG。

照片会上传到网上吗？

不会。所有处理都在你的 Mac 本地完成，App 不联网。

为什么边框位置会微调几个像素？

无损拼接要求左边、上边的边框宽度是 JPEG 数据块（8 或 16 像素）的整数倍，所以边框可能会挪动几个像素，画布总尺寸不变。如果边框太窄、对不齐，App 会自动改用高精度重新编码，并在导出结果里说明。

可以批量处理吗？会覆盖原图吗？

可以把整个文件夹拖进来一次处理完。导出的文件放在你指定的输出文件夹，文件名会加上后缀（默认 _border），永远不会覆盖原图；遇到同名文件会自动加序号。

边框颜色和我选的完全一样吗？

JPG 使用 YCbCr 色彩编码，有些 RGB 颜色没法精确表示，边框颜色可能在某个通道上差 1 个色阶（满分 255）。这已经是标准 JPG 能做到的最好结果，肉眼看不出差别。
